પ્રશ્નોત્તરી

આ પ્રશ્નો અજમાવો. ખાતરી કરવા "જવાબ જુઓ" દબાવો.

1. ડેન્ગ્યુ કયો મચ્છર ફેલાવે છે?
  1. એનોફિલિસ
  2. એડિસ
  3. ક્યુલેક્સ
  4. ઘરમાખી
જવાબ જુઓ
જવાબ: એડિસ

એડિસ, દિવસે કરડતો મચ્છર જે ચોખ્ખા ભરેલા પાણીમાં ઉછરે છે.

2. મેલેરિયા વિસ્તારમાં કોઈને તાવ છે. પહેલું પગલું શું છે?
  1. પેરાસિટામોલ આપીને 1 અઠવાડિયું રાહ
  2. RDT/બ્લડ સ્લાઇડથી તપાસ
  3. એન્ટિબાયોટિક આપવી
  4. 1 મહિનો તાવ રહે તો જ રેફર
જવાબ જુઓ
જવાબ: RDT/બ્લડ સ્લાઇડથી તપાસ

દરેક તાવની 24 કલાકમાં તપાસ કરો.

3. ડેન્ગ્યુમાં તાવ માટે કઈ દવા આપી શકાય?
  1. એસ્પિરિન
  2. આઇબુપ્રોફેન
  3. પેરાસિટામોલ
  4. કોઈપણ દુખાવાની દવા
જવાબ જુઓ
જવાબ: પેરાસિટામોલ

ફક્ત પેરાસિટામોલ. એસ્પિરિન અને આઇબુપ્રોફેનથી લોહી વહી શકે છે.

4. કૂલર અને પાણીની ટાંકી કેટલી વાર ખાલી કરીને સૂકવવી જોઈએ?
  1. વર્ષમાં એક વાર
  2. અઠવાડિયામાં એક વાર
  3. મહિનામાં એક વાર
  4. ક્યારેય નહીં
જવાબ જુઓ
જવાબ: અઠવાડિયામાં એક વાર

અઠવાડિયામાં એક વાર — એડિસનાં ઈંડાં લગભગ 7 દિવસમાં મચ્છર બને છે.

5. ફાઇલેરિયાની MDA ગોળીઓ કોણે ન લેવી જોઈએ?
  1. સ્વસ્થ પુખ્તો
  2. 2 વર્ષથી મોટાં બાળકો
  3. સગર્ભા સ્ત્રીઓ
  4. સ્વસ્થ વૃદ્ધો
જવાબ જુઓ
જવાબ: સગર્ભા સ્ત્રીઓ

2 વર્ષથી નાનાં બાળકો, સગર્ભા સ્ત્રીઓ અને ગંભીર બીમાર લોકોને નહીં.

6. પ્રાઇમાક્વિન કોને ન આપવી જોઈએ?
  1. પુખ્ત પુરુષો
  2. સગર્ભા સ્ત્રીઓ
  3. ખેડૂતો
  4. 8 વર્ષથી મોટાં શાળાનાં બાળકો
જવાબ જુઓ
જવાબ: સગર્ભા સ્ત્રીઓ

પ્રાઇમાક્વિન સગર્ભા સ્ત્રીઓ અને શિશુઓને અપાતી નથી.

infoઆ આશા બહેનોની તાલીમ માટે છે. હંમેશા તમારા ANM, મેડિકલ ઑફિસર અને સરકારની નવી માર્ગદર્શિકાનું પાલન કરો. ઇમરજન્સીમાં 108 પર ફોન કરો.

બધા પાઠવિગતવાર માર્ગદર્શિકાનવું શું છેઅમારા વિશેગોપનીયતા નીતિસંપર્ક
